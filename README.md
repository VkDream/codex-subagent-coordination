# Codex 原生子智能体协作与个性化设置

这是一套个人整理的 Codex 工作约定、原生父子子智能体协作方式、知识库模板和可选角色配置。默认由当前主任务协调需要的子智能体；不要求为每个角色单独创建用户任务页。

本包加入了从个人知识库提炼的通用治理规则和空白模板。它不包含整个知识库、真实项目资料、聊天记录或本机运行配置。

## 协作方式

主任务保留目标、合同、授权、整合和最终结论。存在互不阻塞且边界清楚的工作包时，再派发子智能体。每份派单说明输入、范围、权限、完成条件和直接回包对象；子智能体只向直接父级回传。配置允许的专业角色可以继续派发名单内的专项助手，专项助手是叶节点。

六个职责角色为 01·诊断、02·开发、03·审查、04·修复、05·验证，00·总监由主任务承担。普通分工使用原生父子任务和 optional-config/agents 中的角色提示。kb-role Skill 与页面接力协议配套，仅在明确要求页面式阶段接力时启用。

## 开始之前

1. 阅读 [从零开始指南](从零开始.md) 和 [个性化设置说明](个性化设置.md)。
2. 按自己的项目和知识库修改占位符；不要用示例覆盖现有全局指令或完整 config.toml。
3. 只选择需要的角色配置与 Skill，并确认当前客户端能加载它们。
4. 用一个范围清楚的小任务检查父任务能否派发、等待、接收并核对结果。

角色配置中的模型、推理和并发值来自一套个人偏好。客户端支持情况和实际运行状态需要分别核实；配置文件存在不等于已加载。

本包由个人整理，与 OpenAI 官方产品无关。它不能保证模型、工具、权限或验收结果适用于所有环境。
