# Headroom 可选离线评估说明

Headroom 未随本包安装，默认不启用。配套的 ../scripts/headroom_offline_eval.py 是评估辅助脚本，不是透明代理、账号配置或节省额度的保证。

只有用户授权评估时，才按 quality-gates.md 的允许/禁止输入类型，在隔离环境中核对当前 headroom-ai 官方文档、依赖版本和本机兼容性。使用不含隐私的合成样本或另获授权的代表数据；保留原始输入和关键标记，结果只证明这些样本。

脚本会使用临时目录及指标数据库，临时设置并恢复相关环境变量；显式指定 --output 会创建或覆盖该报告路径。它不是隐私扫描器，输入名称、关键标记和错误信息可能进入输出。虽然脚本本身没有直接网络调用，不能据此保证第三方依赖从不联网。需要严格离线时，由环境提供可核验的网络限制。

分享包检查只覆盖脚本语法及文件完整性；没有安装 Headroom、运行真实压缩或验证节省比例。历史的本机版本、兼容补丁和模拟成绩不作为他人环境的默认事实。
