# 运行时能力检查

此分享包提供文本规则、角色 Skill 与本地辅助脚本，不提供 MCP 服务、账号、模型权限、浏览器会话或 Codex 宿主接口。

对当前任务只检查最窄的相关能力：

- OpenAI 官方事实：可调用的 OpenAI Developers Docs；不可用时按主 Skill 回退到官方网页。
- 第三方库和 API：可调用的 Context7 或该能力拥有者的官方文档。
- 工程结构：只有索引属于当前目标且有效时使用 CodeGraph；修改前核对物理源码。
- 本地文件：定向读取与非 Git 检查；工具可用不扩大读取范围。
- 六角色任务管理：实际暴露的创建任务、读取任务和发送消息接口。没有接口时不可声称派发成功。
- 浏览器、Windows GUI、外部系统：对应运行时工具和本次授权。
- 子智能体：以宿主实际允许的模型、推理、服务层与并发数为准。

按主 Skill 和全局规则记录 MCP_ROUTE、MCP_EVIDENCE、MCP_FALLBACK。配置存在、插件名称和 enabled 状态不是工具已调用的证据。宿主能力不足时报告缺口，继续其余安全工作；不得补造接口或通过复制本包宣称补齐能力。
