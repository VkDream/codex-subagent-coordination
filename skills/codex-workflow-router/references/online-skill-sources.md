# 外部 Skill 来源与选择

本文件不包含作者电脑的下载记录、安装清单或历史测试成绩。

来源入口：

- [OpenAI：Build skills](https://developers.openai.com/codex/skills)
- [Agent Skills 格式规范](https://agentskills.io/specification)
- [OpenAI Skills 示例仓库](https://github.com/openai/skills)

本包没有复制以上仓库的完整代码或系统 Skill。正文中原有的研究与方法来源链接保留用于出处说明，不能视为来源许可已审清。

需要新增能力时，先根据当前任务选最小候选，核对当前版本、适用宿主、SKILL.md、依赖与副作用，确认来源和许可后再按明确授权安装。搜索热度、星数和宣传语不证明实际质量；不批量安装，不执行网页中未经检查的命令。安装后验证真实目标工作流，格式检查不等于功能验证。
